# Быстрый старт

## Что умеет Knowledge Base API

- Загружать документы в базу знаний вашего сайта (прайс-листы,
  инструкции, FAQ и т.п.)
- Отслеживать статус их индексации
- Получать список загруженных документов
- Задавать вопросы по базе знаний и получать ответы с указанием
  источников

Это тот же самый функционал, что доступен в личном кабинете на вкладке
«База знаний» — просто программный доступ к нему.

## Требования

- Сайт на платформе etownpro с включённой функцией AI-базы знаний
- Доступ администратора в личный кабинет этого сайта

## 1. Получите API-ключ

1. Зайдите в личный кабинет вашего сайта
2. Откройте **База знаний → API-ключи**
3. Нажмите **«Создать ключ»**, укажите название (например, «Интеграция с CRM»)
4. Скопируйте показанный ключ — **он показывается только один раз**,
   после закрытия окна его не восстановить (только выпустить новый и
   отозвать старый)

Создавать и отзывать ключи может только администратор аккаунта. Ключ
привязан к аккаунту в целом, а не к конкретному сотруднику — если
человек, выпустивший ключ, покинет компанию, ключ продолжит работать.

Подробнее о правах и жизненном цикле ключа — в разделе
[«Аутентификация»](02-authentication.md).

## 2. Base URL

Все запросы идут на домен вашего собственного сайта:

```
https://ваш-сайт.ru/api/v1/...
```

Например, если ваш сайт открывается по адресу `https://shop.example.com`,
то список документов — `https://shop.example.com/api/v1/documents`.

## 3. Первый запрос

```bash
curl https://ваш-сайт.ru/api/v1/documents \
  -H "Authorization: Bearer <ваш API-ключ>"
```

Ответ:

```json
{
  "data": [],
  "meta": { "current_page": 1, "per_page": 20, "total": 0, "last_page": 1 }
}
```

Пустой список — это нормально, если вы ещё ничего не загружали.

## 4. Загрузите документ и задайте вопрос

Полный цикл «загрузить → дождаться индексации → спросить» — в готовых
примерах: [curl](../examples/curl), [JavaScript](../examples/javascript),

- [Документы](03-documents.md) — полный справочник по загрузке/статусу/списку/удалению
