# База собственников и бот для агентов — руководство руководителя

Для агентств недвижимости. Как работает база объектов с контактами собственников,
в которой каждый объект **закрепляется за агентом**, пока тот выходит на связь:
как включить функцию, загрузить таблицу, подключить сотрудников и бота, какие
правила действуют и как следить за работой агентов. Агентам, которые работают в
боте, отдельно передайте [памятку агента](agent-guide.md). Общие вопросы
подключения ботов — в [руководстве по ботам](../bots/user-guide.md).

## 1. Общая идея одним абзацем

В базе хранятся объекты (адрес, площадь, цена, комиссия, кадастровые номера) и
контакты их собственников. Агент в боте находит объект по адресу и нажимает
«Показать контакты» — бот выдаёт телефоны собственника и **на 2 дня закрепляет
объект за этим агентом**: остальные агенты контактов уже не получат. Агент обязан
сообщить результат звонка; от результата зависит, закрепится ли объект за ним
на 3 месяца, перейдёт ли в «поиск собственника» (за новым номером идёт
ответственный сотрудник) или останется свободным с комментарием. Каждое действие
пишется в журнал, который нельзя изменить или удалить. Дополнительно в боте
агенты ведут **своих клиентов** (телефон скрыт от коллег) и получают **ежедневные
задачи** на актуализацию базы.

```
Агент ищет объект → «Показать контакты» (объект закреплён на 2 дня) → звонок → результат → статус и срок
```

Данные хранятся на платформе, а не в Google Sheets: таблица нужна только для
первой загрузки (и повторных догрузок) — так два источника не будут спорить о том,
кто закрепил объект.

## 2. Роли

| Роль | Что может |
|---|---|
| **Агент** | искать объекты, получать контакты (с закреплением), вносить результат звонка, комментировать, вести своих клиентов, получать ежедневные задачи |
| **Ответственный сотрудник** | всё, что агент, **и** добавлять новые контакты собственников, когда агент не смог дозвониться; получает уведомления «нужно найти контакты»; видит раздел «Нужны контакты» |
| **Руководитель** | видит всё и правит базу в веб-админке: объекты, клиенты (с телефонами), сотрудники, правила, статистика; передаёт клиентов между агентами. **Администратор сайта — всегда руководитель.** |

Ответственных сотрудников может быть несколько — уведомление получат все.
Одному человеку назначается одна роль. Раздел «База собственников» в админке
видят только руководители; агенты и ответственные работают в боте.

## 3. Запуск за 6 шагов

1. **Включите функцию.** Она включается платформой для вашего сайта по заявке в
   поддержку etownpro (укажите, кто будет руководителем, ответственными и
   агентами — по email). После включения в меню админки появляется пункт
   **«База собственников»**.
2. **Убедитесь, что сотрудники зарегистрированы на сайте** по тем же email, на
   которые вы назначаете роли.
3. **Назначьте роли:** «База собственников» → вкладка **«Сотрудники»** →
   введите email, выберите роль, нажмите **«Назначить»**. В таблице
   администраторы сайта показаны как руководители автоматически.
4. **Загрузите объекты:** вкладка **«Объекты»** → **«Загрузить из таблицы (CSV)»**
   ([раздел 4](#4-загрузка-базы-из-таблицы-csv)). Объекты можно добавлять и
   вручную кнопкой **«Добавить объект»**.
5. **Подключите бота:** раздел **«Боты»** → **«Подключить бота»** → сценарий
   **«База собственников (для агентов)»** → токен от BotFather (Telegram) или
   Max. Подробно — [руководство по ботам](../bots/user-guide.md#2-как-подключить-бота--по-шагам).
6. **Пригласите сотрудников в бота:** «База собственников» → «Сотрудники» →
   кнопка **«Приглашение»** напротив человека. Откроется окно со ссылкой и
   командой — отправьте их сотруднику. Он открывает ссылку, нажимает «Запустить»,
   и его чат привязывается к его учётной записи. Ссылка **одноразовая, действует
   7 дней**; можно вместо ссылки отправить боту команду вида `/join КОД`.

Для проверки подключите бота себе: в карточке бота есть кнопка **«Подключить мой
чат»**.

## 4. Загрузка базы из таблицы (CSV)

Выгрузите лист Google Sheets (или Excel) в **CSV**: *Файл → Скачать →
Значения, разделённые запятыми (.csv)*. Порядок колонок не важен, лишние колонки
игнорируются, главное — **заголовки в первой строке**. Разделитель определяется
сам (запятая, точка с запятой, табуляция).

| Колонка (заголовок) | Что хранится | Формат |
|---|---|---|
| **ID** | внутренний номер строки таблицы | любой текст; по нему повторная загрузка находит объект |
| **Адрес** | адрес (обязательно) | как в таблице |
| **Площадь** | площадь, м² | число, допустимы запятая и пробелы: `120,5` |
| **Стоимость** | цена | число: `12 500 000` |
| **Комиссия** | комиссия | число |
| **Статус** | статус объекта | «Без статуса», «Закреплен», «Поиск собственника», «Недозвон», «Активен». Пусто — «Без статуса» |
| **Закрепленный агент** | кто закреплён | имя или email сотрудника из системы |
| **Дата закрепления** | с какого числа | `15.07.2026` |
| **Дата окончания закрепления** | до какого числа | `15.10.2026` |
| **Контакты собственников** | телефоны | см. ниже |
| **Кадастровые номера** | кадастровые номера | через запятую, точку с запятой или с новой строки |
| **Комментарии** | комментарий | текст |
| **Дата последнего контакта** | когда последний раз общались | `15.07.2026` |
| **В рекламе** | объект в рекламе | «да» / «нет» |
| **Фото** | чьи фото | «свои» / «интернет» |

**Контакты собственников.** В одной ячейке можно несколько человек и телефонов:

```
Иван +7 900 111-22-33, 8 912 000 00 00; Мария +7 911 222-33-44
```

— точка с запятой (или новая строка) разделяет **людей**, запятая — **телефоны
одного человека**. Имя необязательно. Телефоны приводятся к единому виду
(`8 912…` и `+7 912…` — один и тот же номер).

**Один собственник — несколько объектов.** Если один и тот же телефон указан у
разных объектов, платформа создаёт **одного собственника**. Поэтому при выдаче
контактов бот показывает и **все остальные объекты** этого собственника.

**Что делает повторная загрузка:**

- объекты с известным ID (или, если ID нет, с тем же адресом и площадью)
  **обновляются**, новые — добавляются; ничего не удаляется;
- **статус и закрепление у уже существующих объектов не перезаписываются
  таблицей** — ими управляют агенты в боте. Статус и закрепление из таблицы
  переносятся только для **новых** объектов;
- «Закреплен» из таблицы переносится, только если агент найден в системе и
  срок закрепления ещё не прошёл; иначе объект станет свободным;
- в конце вы видите итог — «создано / обновлено / пропущено» и список ошибок по
  строкам. Строки без адреса пропускаются.

## 5. Статусы объекта и правила закрепления

| Статус | Контакты другим агентам | Что показывается |
|---|---|---|
| **Без статуса** | выдаются; выдача закрепляет объект | — |
| **Закреплён** | не выдаются | агент, дата закрепления, дата окончания |
| **Поиск собственника** | не выдаются | агент, дата начала поиска |
| **Недозвон** | выдаются всем | дата последней попытки, комментарии |
| **Активен** | выдаются всем | дата общения, агент, комментарии |

**Что происходит по шагам:**

1. **Агент нажимает «Показать контакты» на свободном объекте** → бот выдаёт все
   контакты, объект закрепляется за ним на **2 дня**, факт запроса пишется в журнал.
   Если объект уже закреплён за другим, бот ответит: «Объект закреплён за
   агентом Иван Иванов до 15.07.2026» — без контактов.
2. **Агент сообщает результат:**
   - **✅ Дозвонился** — вносит стоимость, комиссию, комментарий и дату; объект
     закрепляется за ним на **3 месяца** (срок можно продлить кнопкой в боте).
     С этого момента он ответственный за объект.
   - **📵 Не удалось дозвониться** (телефон недоступен / не отвечает) — статус
     становится «Поиск собственника», объект остаётся за агентом ещё 2 дня, а
     ответственные получают уведомление «Нужно найти контакты».
   - **💬 Ответил, общение не налажено** — вносит комментарий и дату
     (например, «просил перезвонить через месяц»); статус «Активен», **объект не
     закрепляется**, а следующий агент увидит всю историю.
3. **Ответственный сотрудник** находит новые контакты и добавляет их (в боте или
   в админке). Агент сразу получает «По объекту … добавлены новые контакты» и
   ещё 2 дня на звонок.
4. Если после новых контактов дозвониться снова не удалось, агент **обязан
   оставить комментарий и завершить работу**: статус «Недозвон», объект открыт
   всем.

**Сроки.**

- Закрепление на 2 дня закончилось без результата — объект возвращается в прежний
  статус (обычно «Без статуса»).
- Закрепление на 3 месяца закончилось — объект становится «Без статуса».
- Поиск собственника закончился без действий — «Недозвон».
- За 24 часа до окончания закрепления агент получает напоминание, в момент
  окончания — уведомление о том, что объект снова доступен другим.
- Снятие закреплений делает система сама, раз в 10 минут, без участия
  администратора.

**Защита от выгрузки базы.** Агент может получить контакты не более чем по
**30 объектам в сутки** (число настраивается; 0 — без лимита). Руководитель
лимитом не ограничен. Повторный просмотр контактов своего объекта в лимит не
входит.

**Контакты для руководителя.** Руководитель может посмотреть контакты чужого
закреплённого объекта без закрепления — это тоже пишется в журнал.

## 6. Клиенты агентов

В боте есть кнопка **«Добавить клиента»**: агент вносит имя, телефон, объект
(по адресу или ID, можно без объекта) и комментарий («ищет арендный бизнес до
100 млн…»).

После сохранения **все остальные агенты получают уведомление** «Новый клиент»:
объект, комментарий и имя агента. **Телефона и имени клиента в уведомлении нет.**

| Кто | Что видит | Что может |
|---|---|---|
| Агент, внёсший клиента | всё: телефон, комментарии, историю | править имя и телефон, менять статус, писать комментарии, продлевать закрепление |
| Руководитель | всё (в том числе в админке на вкладке «Клиенты») | то же, плюс передавать клиента другому агенту |
| Другие агенты | имя, объект, комментарии, дату, имя агента; **телефон скрыт** | просить руководителя о передаче (кнопка в карточке) |

**Закрепление.** Клиент закрепляется за агентом на **3 месяца** (6 — если так
принято в вашей компании: настройка «Закрепление клиента за агентом, месяцев»).
Пока оно действует, другой агент **не может внести клиента с тем же номером**: он
получит ответ «Клиент с этим номером уже закреплён за агентом … до …. Передать
клиента может руководитель». Закрепление перестаёт действовать, если срок вышел
или клиент переведён в статус «Отказ» или «Архив».

**Статусы клиента:** Новый, В работе, Назначен просмотр, Ведутся переговоры,
Сделка, Отказ, Архив. Все смены статусов и комментарии сохраняются в истории.

**Передача клиента.** Только руководитель: на вкладке «Клиенты» → открыть клиента →
«Передать другому агенту». Закрепление начинается заново, оба агента получают
сообщение. Если агент нажал «Запросить передачу», руководители получают
уведомление в боте со ссылкой на клиента.

**Журнал.** Каждое открытие карточки клиента любым пользователем пишется в
журнал. Телефон клиента в журнал не попадает.

**Где клиенты в CRM.** Клиент хранится как контакт CRM; ответственным за контакт
становится внёсший его агент, поэтому в общем списке контактов клиента видят
только он и администратор.

## 7. Ежедневная раздача объектов

Раздача помогает актуализировать базу: каждый рабочий день бот сам отправляет
каждому агенту несколько объектов со статусом «Без статуса».

**Включение.** Вкладка **«Правила» → «Ежедневная раздача»**: галочка
**«Раздавать объекты автоматически (пн–пт)»** (по умолчанию выключено), время
раздачи (10:00), конец рабочего дня (18:00), число объектов на агента (5), резерв
в часах (24). Кнопка **«Раздать сейчас»** на вкладке «Раздача» делает то же
вручную — только для тех, кому сегодня ещё ничего не выдавали.

**Кому.** Агентам и ответственным сотрудникам, у которых **подключён чат бота**.
Руководителям объекты не выдаются.

**Что и как.**

- берутся объекты «Без статуса», не закреплённые и не зарезервированные другими;
  вперёд идут объекты, у которых есть контакты собственника, затем те, с кем
  дольше всего не общались;
- один и тот же объект не достаётся двум агентам одновременно; если свободных
  объектов не хватает на всех, они делятся между агентами поровну;
- агент получает сообщение: «Сегодня вам назначено 5 объектов для актуализации.»
  со списком «адрес — площадь» и кнопками для открытия карточки; дальше работа по
  обычному сценарию — контакты, звонок, результат. Список с отметками хода работы
  всегда доступен кнопкой **«📌 Задачи на сегодня»**.

**Резерв.** Выданный объект резервируется за агентом на 24 часа **только под эту
задачу** — другим агентам он остаётся доступен для обычной работы. Если агент не
приступил (не запросил контакты), резерв снимается и объект возвращается в
общий пул. Если приступил — действуют обычные правила закрепления. Если объект
взял другой агент, задача первого закрывается как потерянная.

**Напоминание.** После конца рабочего дня каждому агенту, у которого остались
необработанные объекты, бот один раз отправляет: «Напоминание: у вас осталось 3
необработанных объекта для актуализации.»

**Что считается.**

| Показатель | Что значит |
|---|---|
| Выдано | сколько объектов назначено |
| Обработано | по скольким внесён результат звонка |
| Актуализировано | сколько из обработанных — «дозвонился» или «ответил, общение не налажено» |
| Недозвонов | сколько обработанных закончились недозвоном |
| Работа не завершена | выдано минус обработано |
| Осталось сегодня | выданные сегодня и ещё не обработанные |
| % успешных дозвонов | актуализировано ÷ обработано |
| Без статуса в базе | сколько объектов ещё не тронуто |

Раздача идёт по рабочим дням (понедельник–пятница) в окне от «времени раздачи» до
«конца рабочего дня».

## 8. Админка: что есть на каждой вкладке

Меню → **«База собственников»** (видно руководителям).

**Объекты.** Поиск по адресу, кадастровому номеру, телефону собственника или ID;
фильтр по статусу со счётчиками; таблица с адресом, площадью, статусом, агентом,
сроком закрепления и числом контактов. Нажатие на строку открывает карточку:
правка адреса, площади, цены, комиссии, кадастровых номеров, признаков «в рекламе»
и «фото своё/из интернета»; список собственников с телефонами и добавление
нового контакта; другие объекты тех же собственников; **полная история объекта**.
Кнопки **«Загрузить из таблицы (CSV)»** и **«Добавить объект»**.

**Клиенты.** Клиенты всех агентов: поиск по имени, телефону, объекту; фильтр по
статусу. В карточке — правка данных, статус, комментарии, **передача другому
агенту**, продление закрепления, журнал.

**Раздача.** Сводка за сегодня, 7 или 30 дней: выдано, обработано, осталось,
актуализировано, недозвонов, % успешных дозвонов, объектов без статуса; **рейтинг
агентов** по актуализированным объектам; кнопка «Раздать сейчас».

**Сотрудники.** Список с ролями, смена роли, снятие роли, ссылка-приглашение в
бота, добавление сотрудника по email.

**Правила.** Все сроки, лимит и параметры раздачи (раздел 9).

**Тексты и кнопки.** Здесь вы настраиваете, что и как говорит бот:

- приветствие, подписи кнопок, вопросы бота, сообщения после действий и уведомления
  агентам — все тексты сгруппированы по шагам (меню, поиск, карточка, итог звонка,
  клиенты, уведомления);
- пустое поле — стандартный текст платформы, под полем он показан; кнопка
  «Сбросить» возвращает стандартный текст;
- в текст можно вставить данные кнопками под полем, например `{address}` — адрес
  объекта; в тексте работает простая разметка: жирный `<b>…</b>`, курсив `<i>…</i>`,
  ссылка `<a href="https://…">…</a>`;
- кнопки главного меню можно **скрыть** (например, «Клиенты агентства»). Скрытие
  только убирает кнопку: права доступа не меняются, закрытый телефон клиента
  по-прежнему закрыт;
- готовые **шаблоны** («Короткое меню», «Без клиентов агентства») применяются к
  черновику и дальше правятся как угодно.

В блоке **«Меню бота»** вверху вкладки:

- стрелками меняется **порядок** кнопок главного меню;
- кнопку можно показывать не всем, а только выбранным ролям (агентам, ответственным,
  руководителям);
- **«Добавить пункт»** создаёт свою кнопку: либо с текстом сообщения (например,
  «Акции агентства» или «Регламент работы»), либо со ссылкой на ваш сайт или
  документ (адрес только `https://…`). Своих пунктов может быть до 8.

Роли, как и скрытие, управляют только показом кнопки: права на сами действия
проверяет платформа.

Правки сначала попадают в **черновик** и не меняют бота. Кнопка «Опубликовать»
включает их для агентов сразу; предыдущие версии хранятся в «Версиях», любую можно
вернуть в черновик и опубликовать. Сообщения об ошибках доступа и системные
сообщения платформы остаются стандартными.

## 9. Правила и их значения по умолчанию

| Правило | По умолчанию | Диапазон | Смысл |
|---|---|---|---|
| Закрепление при выдаче контактов, дней | 2 | 1–30 | сколько агент удерживает объект, пока выходит на связь; столько же даётся после новых контактов |
| Закрепление после «Дозвонился», месяцев | 3 | 1–24 | срок закрепления объекта за агентом |
| Закрепление клиента за агентом, месяцев | 3 | 1–24 | 3 или 6 — по правилам компании |
| Лимит выдачи контактов агенту в сутки | 30 | 0–1000 | 0 — без лимита |
| Раздавать объекты автоматически | выключено | — | раздача по будням |
| Время раздачи | 10:00 | — | начало окна раздачи |
| Конец рабочего дня | 18:00 | — | после него приходит напоминание |
| Объектов агенту в день | 5 | 1–50 | размер порции |
| Резерв, часов | 24 | 1–168 | сколько объект зарезервирован под задачу |

Изменения применяются к новым закреплениям; уже выданные сроки не пересчитываются.

## 10. Журнал действий

Журнал ведётся по каждому объекту и клиенту автоматически и **только
дополняется**: изменить или удалить запись нельзя. В нём:

- кто открывал карточку;
- кто получал контакты и когда (в том числе повторные просмотры и просмотры
  руководителем);
- результаты звонков и комментарии;
- смены статусов, цены и комиссии;
- добавленные контакты собственников;
- изменения кадастровых данных;
- выдача задач, окончание закреплений, загрузка из таблицы.

Журнал — основа для разбора спорных ситуаций («кто первым взял объект») и источник
статистики. Просматривать историю можно в карточке объекта и клиента (веб) и по
кнопке «История» в боте.

## 11. Персональные данные

База содержит телефоны собственников и клиентов, а бот выдаёт их сотрудникам.
Поэтому:

- убедитесь, что у вас есть основания хранить и использовать эти данные
  (согласия, договоры, цели обработки);
- давайте роли только тем, кому нужен доступ; снимайте роль при увольнении
  сотрудника (вкладка «Сотрудники» — «Снять роль»; после этого бот перестанет
  показывать ему данные);
- токен бота храните в тайне (см. [руководство по ботам](../bots/user-guide.md#9-безопасность-и-персональные-данные));
- ограничьте число выдач контактов агенту в сутки (по умолчанию 30) —
  это защита от выгрузки базы.

Телефоны клиентов агентов скрыты от коллег на уровне системы, а не только в
интерфейсе бота.

## 12. Ограничения текущей версии

- Источник данных — база платформы. **Двусторонней синхронизации с Google Sheets
  нет**: таблица загружается как CSV (разово и повторно). Запись статусов обратно
  в таблицу — в планах.
- Агенты и ответственные работают в **боте**, руководитель — в веб-админке.
  Веб-версии для агентов нет.
- Правка адреса и площади объекта — в веб-админке, не в боте.
- В боте поддерживаются **Telegram и Max**, личные диалоги (не группы).
- Связка с рекламой (звонки с рекламы по объекту идут на закреплённого агента),
  телефонией и сделками (расчёт безусловного вознаграждения 5%) в этой версии
  не автоматизирована.
- Раздача выдаёт объекты только со статусом «Без статуса» и только агентам с
  подключённым чатом.
- Экспорта базы в CSV из админки пока нет.

## 13. Частые вопросы

**Агент пишет «У вас нет доступа к базе собственников».** Ему не назначена роль.
Вкладка «Сотрудники» → назначьте роль по email.

**Агент пишет, что бот только для сотрудников.** Чат не привязан. Выдайте
приглашение (вкладка «Сотрудники» → «Приглашение») и попросите открыть ссылку.

**Ссылка-приглашение «недействительна».** Она одноразовая и действует 7 дней.
Выдайте новую.

**Роль назначена, а в списке сотрудников человека нет.** Список показывает
пользователей с ролью и администраторов. Проверьте email и что человек
зарегистрирован на сайте.

**Объект завис «за агентом».** Откройте карточку: там видны агент и срок. Сроки
снимаются автоматически (раз в 10 минут). Передать закреплённый **объект**
вручную нельзя; закреплённого **клиента** руководитель передать может.

**Агент жалуется, что не получает контакты.** Возможные причины: объект закреплён
за другим агентом (бот скажет, за кем и до какого числа); исчерпан дневной лимит
выдач; у объекта нет контактов собственника — тогда нажмите «Не удалось
дозвониться», и ответственный найдёт номер.

**Как проверить, что раздача работает?** Включите её в «Правилах», убедитесь, что
у агентов подключены чаты, и нажмите «Раздать сейчас» на вкладке «Раздача».
Автоматическая раздача идёт только по будням в окне между временем раздачи и
концом рабочего дня.

**Когда придёт напоминание об оставшихся объектах?** Один раз после «конца
рабочего дня», в будни.

**Можно ли изменить время раздачи для одного агента?** Нет, настройки общие для
всей базы.

**Как убрать функцию?** Обратитесь в поддержку: функция выключается, а данные
(объекты, клиенты, журнал) сохраняются и вернутся при повторном включении.
