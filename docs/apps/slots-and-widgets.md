# Слоты и виджеты

Виджет — компонент, который сайт встраивает в своё место. Приложение объявляет виджеты в манифесте
(`site.widgets`, `admin.widgets`: `{ "<слот>": "<имя компонента>" }`), а бандл экспортирует `widgets`:

```js
export const widgets = defineWidgets({ CallbackForm, CallbackFloatingButton })
```

## Слоты v1

| Слот | Где | Пропсы `context` |
|---|---|---|
| `property.detail` | под карточкой объекта на публичном сайте | `{ propertyId }` |
| `home.sections` | главная, после секций | — |
| `global` | поверх всех раскладок (плавающие кнопки, баннеры) | — |
| `admin.dashboard` | главная страница админки | — |

Каждый виджет получает `host` и `context`. Ошибка загрузки или рендера убирает только этот виджет.

## Страницы админки

`admin.menu` добавляет пункт, `admin.pages` перечисляет пути, бандл `web/admin.mjs` экспортирует
`pages = { '': Component, 'settings': Component }`. Страницы открываются на `/admin/x/<id>/<путь>`.

## Ограничения v1

- Виджеты выполняются **только в браузере** (без SSR): подходят для кнопок, форм и счётчиков, но не для
  индексируемого контента.
- Свои публичные страницы с SSR и замена страниц ядра не поддерживаются.
- Файлы версии отдаются с `immutable`; адрес бандла содержит ревизию установки, поэтому переустановка той же
  версии подхватывается без очистки кэша браузера.
