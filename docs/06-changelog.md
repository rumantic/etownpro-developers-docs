# Changelog

## 2026-08-05 — v1

Первый публичный релиз Knowledge Base API.

- `GET /api/v1/documents` — список документов
- `GET /api/v1/documents/{id}` — статус документа
- `POST /api/v1/documents` — загрузка документа
- `DELETE /api/v1/documents/{id}` — удаление документа
- `POST /api/v1/chat/ask` — вопрос-ответ по базе знаний
- API-ключи выпускаются в личном кабинете (База знаний → API-ключи)

### Известные ограничения

- Нет истории диалога — каждый вызов `chat/ask` независим (см.
  [«Вопрос-ответ»](04-chat.md))
- Нет выбора ограниченных прав ключа при создании — все ключи получают
  полный доступ (см. [«Аутентификация»](02-authentication.md))
- Фиксированный лимит запросов (60/мин на аккаунт), без привязки к тарифу
