# etownpro — документация для разработчиков

Документация публичных API платформы etownpro для разработчиков, которые
интегрируют свои системы с сайтами на нашей платформе.

## Доступные API

### 📚 Knowledge Base API (v1)

REST API для работы с базой знаний вашего AI-сайта: загрузка документов,
статус индексации, список документов, вопрос-ответ по базе знаний. То же
самое, что делает личный кабинет и виджет чата на сайте — но программно,
для интеграции с вашими системами (CRM, внутренние боты, мобильные
приложения и т.п.).

- **[Быстрый старт](docs/01-getting-started.md)** — как получить API-ключ
  и сделать первый запрос
- **[Аутентификация](docs/02-authentication.md)** — формат ключа, права,
  ошибки авторизации
- **[Документы](docs/03-documents.md)** — загрузка, список, статус,
  удаление
- **[Вопрос-ответ](docs/04-chat.md)** — обращение к базе знаний
- **[Ошибки и лимиты](docs/05-errors-and-rate-limits.md)** — коды ошибок,
  rate limiting
- **[Changelog](docs/06-changelog.md)**

Готовые примеры кода: [curl](examples/curl), [JavaScript](examples/javascript),
[Python](examples/python), [PHP](examples/php).

## Быстрый пример

```bash
curl https://ваш-сайт.ru/api/v1/chat/ask \
  -H "Authorization: Bearer <ваш API-ключ>" \
  -H "Content-Type: application/json" \
  -d '{"question": "Сколько стоит доставка?"}'
```

```json
{
  "data": {
    "answer": "Доставка по Москве — 500 ₽, бесплатно от 5000 ₽.",
    "sources": [
      { "document_id": "42", "file_name": "price-list.pdf", "section": "delivery", "chunk_index": 3 }
    ]
  }
}
```
